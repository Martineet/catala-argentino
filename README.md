# 📓 Català per a Argentins — Workbook

Aplicació web per aprendre català, pensada per a parlants d'argentí.

## 🚀 Com pujar-ho a GitHub Pages

### 1. Crea un repositori a GitHub
- Ves a [github.com](https://github.com) i crea un repositori nou.
- Posa-li el nom que vulguis, per exemple: `catala-workbook`
- Deixa-ho **públic** (necessari per GitHub Pages gratuït)

### 2. Puja els arxius
Puja aquests 3 arxius al repositori:
- `index.html`
- `style.css`
- `app.js`

Pots fer-ho arrossegant els arxius directament a la pàgina del repositori.

### 3. Activa GitHub Pages
- Ves a **Settings** → **Pages**
- A "Source", selecciona **Deploy from a branch**
- Selecciona la branca `main` i la carpeta `/ (root)`
- Clica **Save**

### 4. Accedeix a la pàgina
En uns minuts la teva pàgina estarà disponible a:
```
https://<el-teu-usuari>.github.io/<nom-del-repositori>/
```

## 📱 Funcionalitats

- **Taula de paraules**: Veu totes les cartes apreses, ordena per català, argentí o dificultat
- **Cerca**: Filtra les paraules en temps real
- **Mode examen**: Practica amb targetes aleatòries i porta el compte de punts
- **Afegir paraules**: Afegeix noves cartes des de qualsevol lloc
- **Persistència**: Les paraules es guarden al navegador (localStorage)

## 💡 Dreceres de teclat (mode examen)

- `Espai` → Revela la resposta
- `→` o `Enter` → Encertat (+1)
- `←` → Fallat (-1)
- `Esc` → Tanca el modal
